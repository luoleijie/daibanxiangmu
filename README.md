# daiban

一个简单、轻量的智能待办清单项目。

## 项目介绍

daiban 用于记录任务、管理日常计划，并作为 AI 辅助开发实验项目。

## 功能

- 新增任务
- 删除任务
- 完成状态切换
- 任务分类查看
- 本地数据保存
- 桌面端与移动端适配

## 技术实现

采用简单直接的前端技术：

- HTML
- CSS
- JavaScript
- 浏览器 localStorage

无需后端、无需数据库，打开网页即可使用。

## 项目结构

```text
index.html   网页结构
style.css    页面样式
script.js    功能逻辑
README.md    项目说明
```

## 发布方式

项目支持 GitHub Actions 自动发布。

修改 main 分支后，会自动更新网页版本。
